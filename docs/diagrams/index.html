如何重新生成

每张图都是同一条命令的产物，exit 0 才算通过；改 packages/mik/src/** 后若行号漂移，按诊断改回真实行号即可。

ARCHIFY_UPDATE_CHECK_DISABLED=1 node .agents/skills/archify/bin/archify.mjs finalize <type> \
  .archify/<workdir>/candidate.json docs/diagrams/<name>.html \
  --repo-root . --quality showcase --json

权威依据是仓库内已批准的文档：docs/SPEC.md（定位与口径）、docs/interfaces.md（接口契约）、docs/decisions.md（D1–D9 取舍）。

做图过程中发现、但未擅自改动的文档漂移已登记在 README.md（每处附取证命令）。

缩略图用 ?embed=1 内嵌各图（隐藏其工具栏与页头），整张图按自身比例缩放显示，不裁切。

每张图另有 png/<name>.png 位图版（含标题与图例的图表卡样式，3.6k–4.9k 像素宽），由产物自身的「导出 → PNG」在同一 Chrome 中生成（见 .archify/export-png.mjs）。
