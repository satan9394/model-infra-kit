# EVO-G88 — 收口：消除剩余的「静默误导」与口径不一致

> 卡号 G88（P2，收口片）· 来源：G82 / G84 / G85 三次验收留下的**登记项**（见 `.tmp/eval-G85.md`、`.tmp/eval-G84.md`、`.tmp/audit-R232.md`）
> 读卡前先读 `AGENTS.md` 与 `docs/interfaces.md`

## 一句话

本片把三处**同类残留**一次收掉：产品仍在**用户没要求时静默地做了某事**，或**同一件事在两处口径不一致**。

## 三件事（**高度耦合：都是「不要静默／不要两套口径」**）

### A. 看板与 REPL 的金额精度与 CLI 口径不一致（G85 登记）

G85 让**用量面**金额在有余数时印 6 位小数（`formatUsageMoney`），但**看板**（`apps/dashboard/lib/format.ts`、`overview.tsx`）与 **REPL**（`src/cli/repl.ts`）**仍是 4 位**。
→ 后果：**同一笔开销，在终端与看板上显示的位数不同**，用户会怀疑哪个是对的。请让它们**采用同一约定**（看板若要引入与 CLI 相同的条件精度，注意它不依赖 CLI 的模块——**以适合看板的方式实现同一规则**，不要把 CLI 代码硬塞进看板）。

### B. 重跑 `init` 会静默丢弃既有的 `cacheDir`（G84 登记）

G84 让 `init --cache-dir` **真正落盘**了。但**重跑 `init` 且不带该 flag** 时，会把配置文件里**既有的 `cacheDir` 一并重写掉**，用户**静默地**落回主目录缓存——**与 G84 刚修好的是同一类「静默撤销用户的配置」**。
→ **要求**：**要么保留既有值**（推荐：flag 缺省时沿用文件里的值，而不是写回默认），**要么明确告知**。**不接受第三种：静默丢弃。** 你判断哪种更合适并说明理由。

### C. `trends` 只给 `--to` 时会静默补一个 30 天下沿（G82 登记）

只传 `--to`（不传 `--from`）时，`applyDays` 会**静默**把下沿设为 30 天前。G79 已为「默认窗口」加了范围说明，但**这条一侧边界的情形没有说明**。
→ **要求**：当**下沿是被工具自己补出来的**，用户必须能**看见**它（沿用 G79 已有的中性范围说明风格，**不要新造一套文案**）。另：**`--days N` 目前没有测试**，请补上（含 `N` 边界：`1`、极大值、非法值）。

## 不能破坏什么

- **金额仍以整数微美元为真源**；禁止 `SUM(CAST(cost AS REAL))`。
- **G77 折叠库提示、G78 未定价「至少」下限、G79 范围说明、G85 的条件精度**都**不得回退**。
- **`usage export` 的 22 列与前 15 列字面量锁不变**；`usage logs` 默认输出逐字不变（`--with-id` 才追加）。
- 契约同步（硬性规则 5）：任何用户可见的输出变化要更新 `docs/interfaces.md`，并在报告中写明**用户会看到什么变化**。
- 既有测试全绿；`tsc` 0；字典 zh/en 对等；看板构建（如有）不破。

## 验收标准

- **A1（口径一致）**：给出**同一笔金额**在 CLI / 看板 / REPL 三处的**真实输出**，证明位数规则一致（或明确说明你为何选择某处不同并给出理由）。**改前必须能红**。
- **A2（`cacheDir` 不再静默丢失）**：构造「先带 `--cache-dir` 落盘 → 再不带该 flag 重跑」的序列，断言既有值**被保留**（或**被明确告知**）；给出改前（值被改写）与改后的**真实配置内容对照**。**改前必须能红**。
- **A3（一侧下沿可见）**：`trends --to <日期>`（不给 `--from`）时，输出中**能看见下沿是工具补的**；给出改前（静默）与改后（可见）的真实输出。
- **A4（`--days N` 有测试）**：`1` / 极大值 / 非法值 三种情形都有断言，且**说明各自期望行为**。
- **A5**：`typecheck` 0；全量测试在 **zh-CN** 与 **`LC_ALL=en_US.UTF-8`+`LANG=en_US.UTF-8`** 下均全绿（**基线 680**，37 文件）；`e2e` exit 0；`check-envs` 三环境 PASS；字典对等。
- **A6（自检）**：新断言**改前必须能红**（G43）；报告指出**未覆盖**的分支（R208）；凡断言「没有 X」，期望值来自被检验对象之外（R231）。
