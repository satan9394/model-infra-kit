# EVO-G89 — 弃用点估计 `costUsd`，并停止在产品内部消费它（minor）

> 卡号 G89（**minor**，`0.3.0`）· 来源：G75 的验收登记 + G78（下限表达）+ G85（精度）
> 读卡前先读 `AGENTS.md` 与 `docs/interfaces.md`

## 一句话

`UsageSummary.costUsd` 是**点估计**。当库里存在**未定价或已折叠**的请求时，它**不是任何一侧的界**（`low ≤ usd ≤ high` 成立，故它**不能**当作下限用——G78 已据此改用 `costLowUsd`）。本卡把它**标记为弃用**（**不删除**，删除属 major），并**停止在产品内部消费它**。

## 目标

1. **弃用**：公共类型 `UsageSummary.costUsd` 加 `@deprecated`，**写清原因与迁移路径**；字段**继续填充**（**非破坏**），保证既有宿主不崩。
2. **内部不再消费**：产品自身（CLI / 看板）**不要再用这个含糊字段**去表达「总额／成本」——凡有更诚实的选择，就用它（`costLowUsd`/`costHighUsd` 或既有的下限表达语义）。
3. **契约与迁移说明**：`docs/interfaces.md` 写明弃用、替代字段、以及「完全定价时 `low == usd == high`」这一事实；发布说明给出迁移写法。

## 为什么这样切

- **minor 只做弃用**：删除公共字段是 **major** 的事。本卡**不删**，只让它不再被推荐、且产品自己不再依赖它。
- **「产品自己不该消费它劝别人别用的字段」**是本卡的核心动机：如果 CLI/看板还在拿 `costUsd` 当总额，那等于**用行动推翻自己的弃用理由**。

## 不能破坏什么

- **`costUsd` 字段继续存在且继续填充**（宿主读取行为不变）。
- **G77 折叠库提示、G78 未定价「至少」下限、G79 范围说明、G85 条件精度**都**不得回退**。
- **金额仍以整数微美元为真源**；禁止 `SUM(CAST(cost AS REAL))`。
- **`usage export` 的 22 列与前 15 列字面量锁不变**；`usage logs` 默认输出逐字不变。
- 既有测试全绿；`tsc` 0；字典 zh/en 对等；看板（`@mik/dashboard`）typecheck 与测试不破。

## 验收标准

- **A1（弃用可见）**：`grep` 给出 `@deprecated` 所在处与真实输出；`docs/interfaces.md` 的弃用段原文可得。**改前必须能红**（改前 `grep -n "@deprecated" ` 在 `costUsd` 处 0 命中）。
- **A2（非破坏）**：断言 `costUsd` **仍被填充**（给真实值/断言），且既有读取方**不崩**。
- **A3（内部不再消费）**：给出**改前改后** CLI 与看板表达「总额/成本」的真实输出，证明产品内部**不再用 `costUsd` 作为该表达的唯一来源**。**改前必须能红**。
- **A4（迁移可执行）**：发布说明与契约里给出**具体迁移写法**（例如「要下限用 `costLowUsd`；要区间用两端；完全定价时三者相等」），且**每一条都与你改后的真实行为一致**。
- **A5**：`pnpm --filter model-infra-kit typecheck` 0；`pnpm --filter '@mik/dashboard' typecheck` 0（**包名从它的 `package.json` 读，不要猜**）；全量 **zh-CN** 与 **`LC_ALL=en_US.UTF-8`+`LANG=en_US.UTF-8`** 均全绿（**基线 686**，38 文件）；看板测试全绿；`e2e` exit 0；`check-envs` 三环境 PASS；字典对等。**build 与测试串行跑**（并发会因 dist 覆写产生假红）。
- **A6（自检）**：新断言**改前必须能红**（G43）；指出**未覆盖**的分支（R208）；**凡断言「某处有/没有某写法」，必须附 `grep` 命令与真实输出**（R258）。

## 版本

- 本卡是 **minor**：`package.json` 从 `0.2.30` → **`0.3.0`**（升版与发布由编排者做，**你不要改版本号**）。

## 范围纪律

**不要**为了「彻底」而**删除** `costUsd`（那是 major）。**不要**顺带重构看板的数据流。若某处必须大改，**停下并申报**。
