# EVO-G74 — 把「未定价覆盖率」变成一眼可见的待办

> 暂存于 `.tmp/`，待转正。**来源**：独立竞品调研 D3（`.tmp/competitor-refresh-2026-09-11.md` §5 D3）+ 编排者综合（`.tmp/competitor-synthesis-R155.md` §2）。
> 覆盖 GAP：**G74**（**P2**）

## 目标

在 `usage summary` 里让用户**一眼看到「有多少钱是我没算准的」**，并**直接告诉他该给哪个模型设 override**。

## 用户场景

用户跑了几天，`usage summary` 显示成本 0.0000 或一个偏小的数。**他不知道这是因为「真的没花多少」还是「一堆模型没定价所以被算成 0」。**

同类最常见的失败**不是「没有成本」，而是「成本看起来正常但是错的/零的」**（外部证据）：
- vercel/ai [#7383](https://github.com/vercel/ai/issues/7383)：Azure 部署名导致 observability 里成本为 0/missing（4 👍）
- vercel/ai [#7412](https://github.com/vercel/ai/issues/7412)：trace 里 duration/token/cost 全是 0
- Langfuse [#10322](https://github.com/langfuse/langfuse/issues/10322)：把 Gemini 的 `total` 当 `completion` → **报价高 8.7 倍**（6 👍、30 条评论）

本产品**已把 `missing` 标出来**（`cost_source: "missing"`，比同类强），但**没有把「我该给哪个模型设 override」变成一眼可见的待办**。

## 当前问题

- `cost_source` **已落库**（既有字段），但 `usage summary` 只给总量，**不给「未定价占比」**；
- 用户要自己 `usage export` 出 CSV 再筛，才能知道哪些模型没定价；
- 因此「未定价」这件事**在默认输出里不可见**。

## 理想行为（纯复用既有数据，不加表、不加列）

1. `usage summary` 增加**一行或一小段**，给出：
   - **未定价请求数 / 占比**；
   - **未定价 token 数 / 占比**（token 维度常比请求维度更能说明金额影响）；
   - **top-N 未定价模型**（按 token 或请求数排序）+ **一条可复制的修法**（`mik pricing set <modelId> --input … --output …`）。
2. **全部计入 0 时不喧哗**：若区间内**没有**未定价请求，则**不打印**该段（或打印一行「全部已定价」）——**避免给健康状态制造噪声**（与 G70 的「输出噪声」价值观一致）。
3. **与既有成本口径不冲突**：`cost_source` 的语义不变；本卡**只做展示**，不改计算。
4. **zh/en 双语**（走既有字典机制）；**数字与模型 id 保持原文**。

## 涉及模块

`src/usage/`（查询层，可能需一条聚合 SQL 或复用既有 rows）、`src/cli/commands/usage.ts`（`summary` 渲染）、`src/cli/i18n/{zh,en}.ts`、`packages/mik/test/`

## 不能破坏什么

- **金额仍以整数微美元累加**（硬性规则 2）；本卡若加聚合，**必须**用 `CAST(ROUND(x*1000000) AS INTEGER)`，**禁止** `SUM(CAST(cost AS REAL))`。
- **`usage export` 的 CSV 表头不变**（外部脚本契约）。
- **`usage summary` 的既有行与顺序不变**（新增段追加在末尾；既有断言不得被改动——**若确需改动，须在报告里逐条说明理由**）。
- 空库 / 零用量时的既有输出**逐字不变**（对照基线）。
- 既有 **510** 例测试全绿；`tsc --noEmit` 0。

## 验收标准

- **A1**：造一批数据（**部分模型有价、部分无价**）→ `usage summary` 打印未定价请求/token **占比**与 **top-N 模型**，且 top-N 里**只含未定价模型**。
- **A2（反向/边界）**：**全部已定价**时，该段**不出现**（或按所选方案为一行中性提示）——`grep` 断言未定价段**不存在**。
- **A3**：**占比分母正确**（未定价请求数 ÷ 总请求数），用**手算的期望值**断言（不得只断言「> 0」）。
- **A4**：`usage export` 的 CSV 表头**逐字不变**（对照基线）。
- **A5**：zh/en 双语；字典键对等（当前 **285**）。
- **A6**：`tsc` 0；全量测试在 **zh-CN 与 en-US** 下均全绿（基线 **510**）；`e2e` exit 0；`check-envs` 三环境 PASS；CI 三 OS 绿。

## 错误场景

- **全部未定价**：占比 100%，top-N 列出全部（或前 N）；**不得**除零崩溃。
- **零请求**：不打印该段（与空库现状一致）。
- **同一模型部分请求有价部分无价**（价格后来才配上）：应如实反映为「一部分未定价」，**不得**按模型去重后误报为「全部已定价」。

## 测试要求

- ≥5 新用例：① 混合有价/无价 → 占比与 top-N 正确（**手算期望值**）；② 全部有价 → 该段不存在；③ 全部无价 → 100% 且不崩；④ CSV 表头不变；⑤ en 对照一条。
- 全部注入 `MIK_LANG`；**不得**读真实 locale。
- **G43 自检**：每条断言在改前必须能红（本卡尤其注意——**「输出含某中文」易恒真**，要断言**具体数字与模型 id**）。
